Our learning approach

About FE Academy

FE Academy was established to make programming and technology easier to understand through guided practice, patient explanations and practical projects. It was founded by Firdaus and Khairi, and later expanded into business and data learning with Asyraf.

Classes are open to learners of all ages and backgrounds. Most monthly-plan classes are conducted in groups. When only one learner joins a scheduled class, the class can continue as an individual session at the same monthly plan price, subject to trainer availability.

Why “Eisner”? It is a reference to Byleth Eisner, the Fire Emblem hero who is also a teacher — a small nod to guidance, growth and learning together. ^_^

Structured three-month programmes

Programme Syllabuses

Each beginner programme runs for an average of 12 weeks. Monthly assessments help learners review their progress, and the final month ends with a practical project and assessment.

Courses can be adjusted to suit the learner's age, experience and learning speed. Some programmes require suitable software or hardware.

Python BeginnerProgramming fundamentals and a final project 12 weeks

Month 1 · Foundations

  1. Week 1: Introduction to programming, installing and using IDLE, comments, print() and basic syntax.
  2. Week 2: Variables, naming conventions, data types, input() and type conversion.
  3. Week 3: if, elif and else, comparison operators, logical operators and decisions using variables.
  4. Week 4: Month 1 assessment and a small decision-making programme.

Month 2 · Building Logic

  1. Week 5: Nested conditionals, input validation and debugging common logic errors.
  2. Week 6: Functions, parameters, arguments, return values and reusable code.
  3. Week 7: for and while loops, range(), counters and repetition.
  4. Week 8: Month 2 assessment with functions, loops and debugging tasks.

Month 3 · Data and Project

  1. Week 9: Lists, indexes, adding/removing items and looping through stored data.
  2. Week 10: Beginner libraries including math and random.
  3. Week 11: Final project planning and development with trainer feedback.
  4. Week 12: Project presentation, final assessment, review and next-step recommendations.
HTML FoundationsBuild well-structured multi-page websites 12 weeks

Month 1 · Web Page Basics

  1. Week 1: How websites work, code editor setup, file organisation and the HTML document structure.
  2. Week 2: Headings, paragraphs, text emphasis, line breaks, comments and clean indentation.
  3. Week 3: Links, file paths, images, alternative text and navigation between pages.
  4. Week 4: Month 1 assessment: create a personal profile web page.

Month 2 · Useful Page Elements

  1. Week 5: Ordered lists, unordered lists and structured information.
  2. Week 6: Tables, captions, headings and accessible data presentation.
  3. Week 7: Forms, labels, text fields, radio buttons, checkboxes and buttons.
  4. Week 8: Month 2 assessment: build a small multi-page information website.

Month 3 · Complete Website

  1. Week 9: Semantic elements such as header, nav, main, section, article and footer.
  2. Week 10: Audio, video, embeds, accessibility and responsible use of online media.
  3. Week 11: Final website planning and development.
  4. Week 12: Testing links, final assessment, presentation and basic publishing guidance.
CSS FoundationsStyle responsive and attractive websites 12 weeks

Recommended prerequisite: basic HTML.

Month 1 · Styling Fundamentals

  1. Week 1: CSS purpose, syntax, comments and linking an external stylesheet.
  2. Week 2: Selectors, colours, backgrounds, fonts, text alignment and units.
  3. Week 3: The box model: margin, border, padding, width and height.
  4. Week 4: Month 1 assessment: style an existing HTML page.

Month 2 · Page Layout

  1. Week 5: Display types, positioning basics and organising page sections.
  2. Week 6: Flexbox alignment, spacing and responsive rows/columns.
  3. Week 7: CSS Grid for cards, galleries and page layouts.
  4. Week 8: Month 2 assessment: recreate a responsive page layout.

Month 3 · Responsive Design

  1. Week 9: Media queries, mobile-first thinking and responsive images.
  2. Week 10: Hover states, transitions, CSS variables and design consistency.
  3. Week 11: Final responsive website design project.
  4. Week 12: Accessibility checks, polishing, final assessment and presentation.
Arduino BeginnerElectronics, sensors and a working prototype 12 weeks

Month 1 · Electronics and Output

  1. Week 1: Electronics safety, Arduino board tour, Arduino IDE, uploading code and the Blink example.
  2. Week 2: Breadboard basics, LEDs, resistors, digital output and simple timing.
  3. Week 3: Buttons, digital input, pull-up resistors and controlling an LED.
  4. Week 4: Month 1 assessment: build a button-controlled traffic light.

Month 2 · Sensors and Feedback

  1. Week 5: Analogue input with a potentiometer or light sensor and reading values in Serial Monitor.
  2. Week 6: PWM, LED brightness and beginner buzzer control.
  3. Week 7: Ultrasonic distance sensor, measurements and threshold decisions.
  4. Week 8: Month 2 assessment: create a sensor-based warning system.

Month 3 · Motion and Prototype

  1. Week 9: Servo motor control and mapping sensor values to movement.
  2. Week 10: Functions, combining components, troubleshooting circuits and project planning.
  3. Week 11: Final prototype construction and testing.
  4. Week 12: Prototype demonstration, final assessment and improvement discussion.
Scratch Creative CodingAnimation, game logic and a final game 12 weeks

Month 1 · Animation Basics

  1. Week 1: Scratch interface, sprites, the stage, events and sequencing blocks.
  2. Week 2: Motion, directions, coordinates and moving to exact positions.
  3. Week 3: Looks, costumes, sound, speech and simple animation timing.
  4. Week 4: Month 1 assessment: create a short interactive animation.

Month 2 · Game Logic

  1. Week 5: Variables, operators, scores, timers and lives.
  2. Week 6: Sensing, if conditions, keyboard input and collisions.
  3. Week 7: Repetition, forever loops, repeat blocks and nested control.
  4. Week 8: Month 2 assessment: build a playable mini game.

Month 3 · Advanced Creation

  1. Week 9: Clones, spawning objects and managing repeated game elements.
  2. Week 10: Broadcast messages, scene changes and custom blocks.
  3. Week 11: Final game planning, building and playtesting.
  4. Week 12: Debugging, final assessment, game presentation and peer feedback.
Power BI for Business & Data ReportingFrom messy data to a business-ready dashboard 12 weeks

Month 1 · Power BI and Data Preparation

  1. Week 1: What Power BI is, Power BI vs Excel, Desktop/Service/Mobile, interface tour, datasets, reports and dashboards. Create a first .pbix report.
  2. Week 2: Import Excel, CSV and folder data; introduction to Power Query and why clean data matters.
  3. Week 3: Remove duplicates, rename columns, change data types, filter rows, split/merge columns and handle missing values.
  4. Week 4: Month 1 assessment: clean a messy business dataset and produce a simple report.

Month 2 · Modelling and Dashboard Design

  1. Week 5: Data models, fact and lookup tables, relationships, one-to-many cardinality and common modelling mistakes.
  2. Week 6: Bar, column, line, table and matrix visuals; when to avoid pie charts and how to choose the right visual.
  3. Week 7: Filters, slicers, drill-down, tooltips, layout, themes and consistent formatting.
  4. Week 8: Month 2 assessment: build an interactive sales dashboard with product, date and region filters.

Month 3 · DAX and Real Business Use

  1. Week 9: DAX fundamentals, calculated columns vs measures, SUM, COUNT and AVERAGE.
  2. Week 10: CALCULATE, filter context, category comparisons and beginner time-based analysis.
  3. Week 11: Publishing to Power BI Service, sharing, manual/scheduled refresh concepts, governance and monthly reporting use cases.
  4. Week 12: Final business dashboard project, presentation, assessment and workplace implementation plan.
